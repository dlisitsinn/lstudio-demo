# Демо-бот LStudio — инструкция

Бот собирает «сайт для клиента» на основе ваших готовых сайтов с GitHub и делает скриншоты, которые можно сразу отправить клиенту.

## Как это работает

1. Клиент ответил: «да, покажите демо».
2. Запускаете **«Запустить демо-бота.bat»**. Откроется окно в браузере.
3. Вставляете ссылку на группу ВК клиента и нажимаете **«Подтянуть из ВК»** (в первый раз бот попросит войти во ВК — см. ниже). Бот сам возьмёт название, описание, телефон, адрес, часы работы, товары с ценами и фото.
   Если группы нет или цен там нет, впишите всё вручную.
4. Проверяете образец сайта (бот подбирает его сам по названию), поправляете поля, добавляете или убираете фото.
5. Нажимаете **«Собрать сайт и сделать скриншоты»**. Через 10–20 секунд справа появятся скриншоты.
6. Нажимаете **«Открыть папку со скриншотами»** и отправляете клиенту картинки:
   - `pc-1-first-screen.png` — первый экран на компьютере;
   - `phone-1-first-screen.png` — первый экран на телефоне;
   - `pc-2-page-01.jpg`, `02`… — весь сайт по кускам, если клиент хочет посмотреть всё.

Первый запуск дольше (1–3 минуты): бот один раз скачивает модуль для скриншотов.

## Образцы

| Образец | Для кого | Ваш сайт |
|---|---|---|
| Салон красоты | маникюр, брови, ресницы, парикмахерские, массаж | velvet |
| Детейлинг и автосервис | мойки, детейлинг, шиномонтаж, СТО | radiant-ride |
| Ремонт, стройка, интерьер | ремонт квартир, отделка, мебель, кухни | pure-vision |
| Кафе и ресторан | кафе, бистро, рестораны, кофейни, пиццерии | pion |
| Столовая, домашняя кухня | столовые, комплексные обеды, банкеты | cafe-astoria |
| Цветы и подарки | цветочные, флористы, шары, подарки | sally |

Бот каждый раз берёт свежую версию образца с GitHub. Если вы поменяете сайт-образец, демо тоже изменится.
Если поменять в образце структуру (переименовать блоки), часть подстановки может перестать работать — тогда напишите Claude, он поправит шаблон в папке `templates`.

## Как вписывать цены списком

Нажмите «Вставить списком» и вставьте текст:

```
# Ногти
Маникюр с покрытием — 1500
Педикюр — от 2000 | с покрытием
# Брови
Коррекция бровей 600
```

- каждая позиция с новой строки, цена в конце;
- после `|` можно добавить описание;
- строка с `#` — название раздела (например, разделы меню в кафе).

Фото к конкретной позиции — перетащите картинку на квадратик слева от строки.

## Фото

- Первое фото идёт на главный экран. Порядок меняется перетаскиванием.
- Позиции с фото показываются карточками («работы», «каталог»).
- Если фото нет, на сайте остаются красивые фото из образца.

## Вход во ВК (один раз)

Бот читает группы через своё окно Chrome — как основной бот, без токенов.
В первый раз нажмите **«Войти во ВК через Chrome»**: откроется окно, войдите во ВК как обычно (лучше со второй страницы). Окно закроется само.
Дальше «Подтянуть из ВК» работает без окна: бот сам открывает группу, берёт название, описание, телефон, адрес, фото и товары с ценами (если они есть в разделе «Товары»).
Если бот напишет «ВК просит войти заново» — нажмите кнопку ещё раз.
Если меню или товары лежат в ВК отдельной страницей, вставьте её ссылку во второе поле — бот прочитает все позиции оттуда.

## Где что лежит

- `sites/` — все собранные сайты со скриншотами (кнопка «Папка с готовыми сайтами.bat»);
- `data/` — загруженные фото и скачанные образцы;
- обновления бота с GitHub эти папки и файл `.env` не трогают.

Сайты-демо закрыты от поисковиков и счётчика Яндекс.Метрики. Чужое название в Google не попадёт.
